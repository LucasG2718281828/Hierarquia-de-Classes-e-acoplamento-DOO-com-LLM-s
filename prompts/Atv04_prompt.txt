Implemente em Java as classes 'ContaCorrente' e 'ContaPoupanca' que herda de 'ContaBancaria'. A classe ContaBancaria possui metodos sobre Aplicar tarifas bancárias específicas sobrescrevendo método sacar(). deve-se ter acopladas/dependencias 'Titular', 'Extrato' e 'Moeda'. Gere o código completo da hierarquia principal e stubs para as dependências. Importante: Gere o código completo (com atributos e métodos) apenas para a Classe Pai e as Classes Filhas. Para as classes de dependência (ex: Motor, Placa, GatewayPagamento), gere apenas a estrutura básica da classe (esqueleto) com métodos vazios, o suficiente para que o código compile.
