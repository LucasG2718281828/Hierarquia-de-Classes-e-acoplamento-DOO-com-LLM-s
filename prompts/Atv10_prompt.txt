Implemente em Java as classes SensorTemperatura, SensorPressao que herda de 'SensorIoT'. A classe SensorIoT possui metodos sobre Calibrar e transmitir leituras ambientais via protocolo MQTT. deve-se ter acopladas/dependencias ConexaoMqtt, Calibrador, LogManager, PayloadTelemetria. Gere o código completo da hierarquia principal e stubs para as dependências. Importante: Gere o código completo (com atributos e métodos) apenas para a Classe Pai e as Classes Filhas. Para as classes de dependência (ex: Motor, Placa, GatewayPagamento), gere apenas a estrutura básica da classe (esqueleto) com métodos vazios, o suficiente para que o código compile.
