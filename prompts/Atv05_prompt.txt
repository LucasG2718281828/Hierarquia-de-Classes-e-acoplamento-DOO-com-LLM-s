Implemente em Java as classes 'Smartphone' e 'Tablet' que herda de 'DispositivoEletronico'. A classe DispositivoEletronico possui metodos sobre Gerenciar ciclo de bateria e especificações de hardware portátil. deve-se ter acopladas/dependencias 'Bateria' e 'Fabricante'. Gere o código completo da hierarquia principal e stubs para as dependências. Importante: Gere o código completo (com atributos e métodos) apenas para a Classe Pai e as Classes Filhas. Para as classes de dependência (ex: Motor, Placa, GatewayPagamento), gere apenas a estrutura básica da classe (esqueleto) com métodos vazios, o suficiente para que o código compile.
