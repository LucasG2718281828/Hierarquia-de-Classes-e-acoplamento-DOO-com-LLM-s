Implemente em Java as classes NotaFiscalEletronica, CupomFiscal que herda de 'DocumentoFiscal'. A classe DocumentoFiscal possui metodos sobre Validar, assinar digitalmente e calcular alíquotas de impostos fiscais. deve-se ter acopladas/dependencias Emitente, Destinatario, ItemTributado, CertificadoDigital, RepositorioXml, ImpostoCalculador. Gere o código completo da hierarquia principal e stubs para as dependências. Importante: Gere o código completo (com atributos e métodos) apenas para a Classe Pai e as Classes Filhas. Para as classes de dependência (ex: Motor, Placa, GatewayPagamento), gere apenas a estrutura básica da classe (esqueleto) com métodos vazios, o suficiente para que o código compile.
